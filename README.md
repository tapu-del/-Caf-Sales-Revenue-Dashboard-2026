# -Caf-Sales-Revenue-Dashboard-2026
## About the Project
This project is an interactive Power BI dashboard built to analyze café sales data. The goal was to track total revenue, item sales, and understand customer payment preferences and location trends.

## Tools & Skills Used
* Power BI
* DAX (Data Analysis Expressions)
* Data Modeling
* Dashboard Design (Custom Cream & Coffee Brown Theme)

## Key Metrics Analyzed
* **KPI Cards:** Total Quantity Sold, Total Revenue, and Total Transactions.
* **Location Analysis:** A Donut Chart showing average spend by In-store vs Takeaway.
* **Payment Methods:** A Treemap showing the count of transactions by Digital Wallet, Credit Card, and Cash.
* **Item Performance:** A Funnel/Bar Chart showing which items sell the most.
* **Interactive Filter:** A Date Slicer to filter the entire dashboard by specific dates.
